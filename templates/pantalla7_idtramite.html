📋 Registrar Código Trámite (ID_TRAMITE)

Paso 7 de 8

📌 Copia y pega los ID_TRAMITE (Códigos Trámite) devueltos por el sistema externo

El sistema externo generó los ID_TRAMITE (Códigos Trámite) al ejecutar los scripts anteriores.

Copia y pega la lista de ID_TRAMITE que te devolvió el sistema externo.

El sistema asignará cada Código Trámite a cada trabajador respetando el orden del Excel.

Ejemplo: Si el sistema externo te devolvió:
727703, 727704, 727705, 727706, 727707
→ Se asignan en ese orden a los trabajadores del Excel.

💡 Nota: El Código Trámite que ves en la planilla es el mismo ID_TRAMITE que se usará en el script SQL.
